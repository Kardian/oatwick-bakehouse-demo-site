# Oatwick Bakehouse: demo website

A complete five-page static website for **Oatwick Bakehouse**, a **fictional** neighbourhood sourdough bakery. Built from scratch as a demo: plain HTML and hand-written CSS, a few lines of JavaScript for the pre-order form, no framework and no template.

Live: https://kardian.github.io/oatwick-bakehouse-demo-site/

The business, people, address (14 Mercer Row, Fairhaven), phone ((555) 014-2207) and email (hello@oatwick.example) are invented. The pre-order form only opens the visitor's own email app; nothing is sent to a server.

See `CREDITS.md` for images and fonts.
